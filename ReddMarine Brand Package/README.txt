REDD MARINE — BRAND PACKAGE
================================================================
Generated from the newest logos in /BRANDING, keeping the same
retro-marine style: cream field, thin frame, one-point-perspective
dock, heavy REDD wordmark, Signal-Red band, letter-spaced MARINE.

Every logo is built directly from your original brand artwork
(the exact Glacial Indifference letterforms and the original dock),
recoloured to the true brand palette. Each is provided as a high-
resolution PNG plus an SVG (which embeds the same artwork). The
letterforms therefore match your source logos exactly, and render
without needing the font installed. (If you later have a vector-
tracing tool, these can be converted to fully editable vectors.)

TYPEFACE
----------------------------------------------------------------
Glacial Indifference — the sole brand typeface.
  REDD    Bold, tight tracking, all caps (logotype / headlines)
  MARINE  Regular, wide letter-spacing (supporting text)
Install Glacial Indifference to typeset marketing copy. The logo
files themselves need no font (outlined). Substitute if needed:
Montserrat or Century Gothic.

WEB USAGE
----------------------------------------------------------------
Copy the tags in 03 Favicon & Web/HTML-snippet.txt into <head>,
and drop the matching files at your site root.
