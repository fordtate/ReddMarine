    Step 3 · Put it live

    1. Open github.com/fordtate/ReddMarine
    2. Go to docs → kit → access.json
    3. Click the pencil icon (Edit this file)
    4. Select all in the editor and paste what you copied above
    5. Commit changes → Commit directly to the main branch
    6. Wait about a minute for the site to rebuild, then test the new password at /kit/
    A removed password stops working the moment you commit, but anyone who already opened the kit could have saved the page. Treat removal as closing the door, not as taking the copy back.
